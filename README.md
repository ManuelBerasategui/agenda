# Agenda diaria

Agenda personal por voz. Le contás lo que hiciste o lo que querés hacer y reacomoda el día.

- Los datos se guardan en el navegador de cada dispositivo (Exportar/Importar en Ajustes).
- La interpretación usa Gemini con tu propia clave gratuita, guardada solo en tu dispositivo.
- La voz usa el reconocimiento de voz del navegador.
